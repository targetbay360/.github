## Who we are

TargetBay is an eCommerce-focused technology company. We don't build generic marketing software that happens to work for retail — every product starts from how an online store actually operates: catalogs, carts, orders, repeat purchases, and the customer record that ties them together.

That focus shows up in three ways:

- **Connected, not bundled.** Marketing, reviews, and loyalty share the same customer and order context, so a review request, a points balance, and an abandoned-cart email all work from the same signal.
- **Platform-native.** Products install into the store platform a merchant already runs and read its real data — products, orders, customers — rather than asking for a re-platform.
- **Built for merchant teams.** Pre-built segments, ready-made automations, and template libraries exist because most eCommerce teams are small and need to ship a campaign today.

## Built for eCommerce

Online stores don't have a funnel that ends at purchase. They have a loop:

**Acquire → Engage → Convert → Review → Reward → Retain**

- **Acquire** — pop-ups and signup forms turn store visitors into subscribers.
- **Engage** — segmented email and SMS reach shoppers based on what they browsed and bought.
- **Convert** — abandoned-cart automations recover sessions that stalled before checkout.
- **Review** — post-purchase requests collect reviews, photos, and video from real buyers.
- **Reward** — points, tiers, and referrals make the second order easier than the first.
- **Retain** — reviews feed product discovery, loyalty feeds repeat purchase, and both feed back into who gets messaged next.

Each product covers part of that loop. Running them together is the point.

## Featured project

### [targetbay-agent-skills](https://github.com/targetbay360/targetbay-agent-skills)

An Agent Skills marketplace: vendor-neutral skill packages that teach AI agents *how to accomplish an objective* on a TargetBay product — the reasoning an API or MCP server doesn't carry. Ships as four installable plugins:

- `targetbay-email-sms` — planning, targeting, sequencing, and optimizing email and SMS
- `targetbay-reviews` — when to ask for a review, which products lack proof, where proof belongs
- `targetbay-loyalty` — what a point is worth, where tier thresholds go, which members are leaving

```
/plugin marketplace add targetbay360/targetbay-agent-skills
```

MIT licensed. See the [repository README](https://github.com/targetbay360/targetbay-agent-skills#readme) for install and usage.
